## 🚀 HOW TO RUN (3 Steps)

### Step 1: Backend
```bash
cd parkit-backend
npm install
npm start
# Server runs on http://localhost:5000
```

### Step 2: Mobile App
```bash
cd parkit-mobile
npm install
npm start
# Scan QR code with Expo Go or emulator
```

### Step 3: Admin Dashboard
```bash
cd parkit-admin-web
npm install
npm run dev
# Opens on http://localhost:3000
```

**Total Time**: ~10 minutes (including npm install)
