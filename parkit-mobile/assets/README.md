# Assets

This directory contains the app's visual assets:

- **icon.png** - App icon (192x192px recommended)
- **splash.png** - Splash screen image (1024x1024px recommended)
- **adaptive-icon.png** - Android adaptive icon (192x192px recommended)
- **favicon.png** - Web favicon (192x192px)

## Placeholder Images

The following SVG placeholders have been created for development. Replace with actual assets before production:

- Use a design tool like Figma or Adobe XD to create proper icons
- Ensure icons meet platform requirements (iOS, Android, Web)
- Store high-resolution versions and let Expo's build process resize them
